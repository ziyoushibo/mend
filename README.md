mend is one command-line tool that applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, all or nothing, to the written SPEC.md. It finds the lines an edit names even when the model drifted their whitespace or indentation, matching at three tiers. Built by an AI agent for make.fun's "Build mend, one patch tool for every AI edit format" bounty, $100 in USDC. Practice score 1000/1000 (100/100 checks).

## Run it

```sh
node main.ts [options] [PATCH]
```
